# 構造化ロジスティクス・ダイニング (Structured Logistics Dining)

PHPのオブジェクト指向（OOP）をフルに活用して設計された、1店舗完結型の**リアルタイム店舗経営・物流シミュレーター**です。天候や経済の変動（シグナル）が、仕入れ原価、顧客の動線、厨房のキュー（処理待ち）にどのように連鎖的な影響を与えるかをモダンなWeb UI（ダッシュボード）で視覚的に検証できます。

## 🏛️ システムアーキテクチャ（オブジェクトモデル）

本アプリケーションは、現実の店舗運営ドメインを以下の4つの自律的なオブジェクトレイヤーに抽象化して設計されています。

* **市場環境レイヤー (`MarketEvent`)**
    * 天候や経済イベントをポリモーフィズムによって動的に管理。客足や仕入れ価格の補正係数をカーネルに注入します。
* **ロジスティクスレイヤー (`Inventory`, `StockItem`)**
    * 食材ごとの「TTL（消費期限）」を内部でカウント。FIFO（先入れ先出し）アルゴリズムに基づき、古い食材から自動消費し、営業終了後に期限切れ食材を「廃棄損失」として計上します。
* **厨房リソースレイヤー (`Staff`, `CookingTask`)**
    * 非同期的なマルチタスク・キュー。スタッフの稼働状態（Idle / Busy）を毎分監視し、料理の提供にかかった時間から「サービス品質（QoS）」を動的に算出します。
* **シミュレーション・カーネル (`RestaurantKernel`)**
    * 上記のコンポーネントを統括し、1分間（1 Tick）ごとの営業サイクル（11:30〜12:00）を駆動させる中央エンジンです。
